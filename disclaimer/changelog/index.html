Full changelist

We maintain this page as the public record of everything changed. Entries use major.minor.patch: the 0.0.x line records the first build day, and from 0.1.1 onward every shipped feature gets its own patch version. The old 0.1.1–0.1.6 batch labels have been split and renumbered so one version equals one understandable change. Majors are launch milestones; minor versions mark a new phase. New months, days and versions are listed newest-first. All boxes start closed by default.
