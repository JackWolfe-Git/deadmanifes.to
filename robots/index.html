Purpose

deadmanifesto is the living electronic press kit and portfolio of Ginger Deadman. It presents the discography, photo/press material, career/games work, lifestyle writing, contact routes, shop and copyright/disclaimer info in one ultra-minimalist brutalist placeholder site. Real authored content is still pending and is shown as [TODO: ...] blocks; media is shown as orange placeholders or live embedded widgets where noted.

Structure (top level)

  • index.html — Splash
  • music/index.html — Aggregators, embeds, Lyrics Archive, Flips series, collabs
  • music/albums/... — Song pages
  • ginger-deadman/index.html — Artist profile
  • ginger-deadman/about/... — About, EPK bio, gallery hub + subgalleries
  • deadmanifesto/index.html — Brand hub
  • deadmanifesto/manifesto/...
  • deadmanifesto/services/...
  • deadmanifesto/games/... — Games home + Steam widget
  • deadmanifesto/career/... — CV / career credits
  • deadmanifesto/adhd-guide/..., recipes/..., music-reviews/..., home-studio-101/..., games-blog/..., ai/... — editorial slots
  • shop/index.html
  • contact/index.html — Contact + socials + gaming profiles
  • disclaimer/index.html
  • changelog/index.html
  • robots/index.html — this page

Assets & data

  • style.css — single shared stylesheet, dark/light/orange mode rules, mobile breakpoints
  • assets/theme.js — theme mode persistence + notice
  • assets/images/ — generic SVG icons (placeholder, generic-gaming, generic-music), empty aliases ready for album covers
  • content.md — source of truth for authored text

Maintenance rule

Any major structural change (new page, removed page, moved section, new global asset, new persistent setting) must be reflected in this page immediately, and a matching 0.0.x entry must be added to /changelog/. If you add, rename or delete a directory, update both lists here.
